# Azu Office

Asistente personal y administrativo de Azu.

## Objetivo del piloto

Primero se prueba con un único workspace personal. El núcleo queda preparado para evolucionar a Azu Office multiusuario y, más adelante, conectarse con MI CLUB u otros sistemas.

## Primera etapa

- memoria estructurada
- tareas y recordatorios
- registro de acciones
- documentos
- integración con Google Drive
- integración con Google Calendar
- integración con Gmail

## Arquitectura

- Frontend web liviano
- API serverless en Vercel
- Supabase como almacenamiento
- Integraciones externas por conectores
- Sin secretos dentro del repositorio
